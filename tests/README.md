# Tests

This section contains the fork's safety nets.

- `tests/golden/` — reference CSS generated by the official v4.6.2 build (libsass).
  Any Sass change must produce an empty golden diff after normalization.
- `build/css-normalize.js` — normalizes a CSS file for `diff` comparison.
- `tests/sass/` — sass-true tests and override tests (`@import` and `@use ... with()`).
- `tests/e2e/` — Playwright visual and behavioral tests for each component.
- `tests/unit/` — Vitest unit tests (migrated from QUnit/Karma).
- `tests/adminlte/` — AdminLTE 3 compatibility fixture (aliased to the fork).

## Upstream baseline

- Starting version: `v4.6.2`
- Original QUnit test count: 12 files, ~9,300 lines.
- The original Karma suite cannot run on Node 20+ (node-sass 6).
  Reference results come from upstream CI and the Vitest migration.
