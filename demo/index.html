bootstrap-modernized

Maintained Bootstrap forks, modernized for 2026-era stacks. The pages below run each branch's real dist/ build.

Major version 4 — v4-modern

Bootstrap 4, kept alive

  • Fork of 4.6.2 — stays on major 4
  • jQuery 3.5+ and 4.x
  • Popper v1 replaced by @popperjs/core v2
  • Dart Sass 2/3 clean, parallel @use tree
  • Drop-in for AdminLTE 3 (verified in CI)
Open the v4 demo
Major version 5 — v5-modern

Bootstrap 5, future-proofed

  • Fork of 5.3.8 — stays on major 5
  • Vanilla JS, no jQuery required
  • Popper 2 via @popperjs/core
  • scss/module/ — @use/@forward tree with identical CSS output
  • Deprecation-free Sass for Dart Sass 2/3
Open the v5 demo

Side-by-side

v4-modern v5-modern

All CSS/JS on these pages is served from the committed dist/ output of each branch — nothing comes from a CDN build of upstream Bootstrap.
